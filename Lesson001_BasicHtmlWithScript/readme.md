#   Creating a Basic HTML Page Including a Script
Javascript of ECMA script is one of the most commonly used programming languages. The reason it is so widespread is that it is the native programing language of the web browser. The most common place to find JavaScript code is embedded in web-based applications (although it is used to create all sorts of applications today.)

Because of this, we will be creating our early JavaScript programs inside of HTML web pages.
